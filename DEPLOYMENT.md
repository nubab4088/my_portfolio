# Deployment Guide

## Vercel Deployment (Recommended)

Vercel is the official Next.js hosting platform and offers:
- Zero-configuration deployment
- Automatic edge function optimization
- Free tier with generous limits
- Instant rollback capabilities

### Steps

1. **Create Vercel Account** (if you don't have one)
   - Visit https://vercel.com
   - Sign up with GitHub/GitLab/Bitbucket

2. **Push to GitHub**
   ```bash
   cd /Users/nusrat_bably/Desktop/Portfolio
   git add .
   git commit -m "Complete production-ready portfolio"
   git push origin main
   ```

3. **Import Project to Vercel**
   - Go to https://vercel.com/new
   - Select "Import Project"
   - Paste your GitHub repository URL
   - Click "Continue"

4. **Configure Project**
   - **Project Name**: `nusrat-portfolio` (or your choice)
   - **Framework**: Next.js (auto-detected)
   - **Root Directory**: `.` (default)
   - **Environment Variables**: Leave blank (not needed)
   - Click "Deploy"

5. **Wait for Build**
   - Vercel builds and deploys automatically
   - Takes ~2-3 minutes
   - You get a live URL immediately

6. **Custom Domain (Optional)**
   - Go to project settings
   - Click "Domains"
   - Add your custom domain (e.g., nusratjahanbably.com)
   - Follow DNS configuration steps

### Environment Variables

Not required, but if you add a contact form later:
- `NEXT_PUBLIC_FORM_API`: API endpoint for contact submissions

### Auto-Deploy

Every time you push to `main` branch, Vercel automatically:
- Rebuilds the project
- Runs tests
- Deploys to production
- Keeps previous deployments for instant rollback

## Alternative Deployments

### Netlify

1. Connect GitHub to Netlify
2. Build command: `npm run build`
3. Publish directory: `.next`
4. Deploy

### Self-Hosted (Node.js)

```bash
# On your server
npm install
npm run build
npm start

# Use process manager like PM2
pm2 start "npm start" --name portfolio
```

### Docker Deployment

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

CMD ["npm", "start"]
```

### Static Export (Advanced)

> Warning: This disables dynamic features, but gives ultra-fast static hosting

1. Update `next.config.js`:
```javascript
const nextConfig = {
  output: 'export',
};
```

2. Build and deploy static files:
```bash
npm run build
# Upload contents of `out/` folder to static host
```

## Troubleshooting Deployment

### Build fails on Vercel

Check build logs:
1. Go to project settings
2. Click "Deployments"
3. Click recent failed deployment
4. Review build logs
5. Common issues:
   - Missing environment variables
   - Outdated Node version
   - TypeScript errors

### Deploy fails but local works

Usually caching issue:
1. Clear Vercel cache: Settings → Git → Redeploy
2. Or trigger new deployment: `git commit --allow-empty && git push`

### Slow performance after deployment

1. Check Lighthouse score on Vercel
2. Optimize images if added
3. Check for large dependencies in bundle
4. Use Vercel's analytics to identify bottlenecks
